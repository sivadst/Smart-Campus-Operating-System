Authentication

Write operations and selected personal or administrative resources require a JWT and the appropriate role. Use Swagger UI to authenticate and test protected endpoints. This dashboard does not store passwords or tokens.

Important demo note

A failed endpoint is shown as unavailable; the interface does not fabricate records. Some modules are represented as platform capabilities even if their full UI is not implemented here.
